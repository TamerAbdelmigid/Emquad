Groundwater recharge1
Groundwater Recharge in Arid Basins
Lina Marsh and Omar Faris
October 2026
We estimate how much rain reaches the water table in three desert basins, using the chloride left in the soil and a simple water balance. Recharge is small, under 5 mm a year in most places, but it is concentrated beneath dry riverbeds, where floods soak in.

Introduction

In dry regions almost all rain returns to the air before it can sink below the roots. What little gets through, the recharge, sets how much water can be pumped without emptying the aquifier for good (Scanlon et al., 2006).

This report asks three questions:

  1. How large is recharge in each basin?
  2. Where does it happen?
  3. How has it changed since 1950?

We find that recharge is spread evenly across each basinis concentrated beneath dry riverbeds, as Figure 1 shows.

Method

The chloride mass balance compares the chloride that falls with rain to the chloride left in the soil water:

R = P CPCuz

where P is the yearly rain, CP its chloride concentration and Cuz the concentration below the root zone. Table 1 lists the values for each basin.

In the app

The parts, numbered

Press Number the parts at the top to put these numbers on the mockup. Things to try: select text to get the small toolbar; click the table, the figure or the equation to get their tabs; press Split; drag a heading in Navigation; press Alt for KeyTips; right-click aquifier.

  • 1
    A ribbon with Word's tabs, in Word's placesHome, Insert, Layout, References, Review, View. A Word user finds Bold, Bullets, Margins and Insert Citation where their hands expect them. Every button writes plain LaTeX into the file, as the toolbar already does.
  • 2
    One extra tab: LaTeXThe way into LaTeX's power: Edit as LaTeX, LaTeX blocks, the preamble explained, your own commands, what each button writes. It is the only tab Word does not have.
  • 3
    Styles galleryNormal, Title, Heading 1–3, Quote, Abstract, Code. Each style is a LaTeX command (\section, quote…), so it is what Word's styles were meant to be: structure, not looks.
  • 4
    Visual · Split · CodeSplit shows the page and its LaTeX side by side, with the paragraph you are in lit on both. It is the main way a Word user learns LaTeX without leaving their document.
  • 5
    Navigation paneHeadings you can drag to move a whole section, and page thumbnails from the last compile, like Word's.
  • 6
    Pages, not a code screenA white page with the document's real margins (read from geometry), a ruler, zoom, and gaps where the last compile broke the pages. Today Visual is drawn inside the dark code screen, with line numbers.
  • 7
    LaTeX blocksAnything the editor has no buttons for, such as this TikZ drawing, shows as it prints, from the last compile, with Show LaTeX and Edit. Nothing a power user writes is lost or hidden.
  • 8
    Comments in the marginWord-style balloons beside the page. They are today's comments, stored outside the file. Review ▸ Show changes draws the changes since a snapshot in each author's colour.
  • 9
    The LaTeX pathThe status bar says where the cursor is in LaTeX terms (\section › enumerate › \item › \emph), the way Word's status bar says the page. You learn the structure by watching it.
  • 10
    Tooltips that teachPoint at any button: its name, its shortcut, and the LaTeX it writes. Where LaTeX works differently from Word (fonts, sizes, picture placement), the tooltip says so in one sentence.
  • 11
    Contextual tabsClick into the table, the figure or the equation: a Table, Picture or Equation tab appears, as in Word. They hold today's table editor, caption tool and equation editor.
  • 12
    The page stays drawnUnlike today, the cursor does not turn what it touches back into source. To see source you ask for it: Ctrl+/ on a block, LaTeX marks, or Split.

Rules this design keeps

The product's principles still hold. These are what make a Word-like surface safe on top of a LaTeX file.

The file is the truthEvery button is an edit to main.tex, one undo step, readable in Split. There is no second document model to drift from the source, and no markers in the file.
Structure, not looksWord habits that fight LaTeX (a font per word, 13.5 pt here, a picture nailed to a spot) are offered in their LaTeX form, with one sentence saying why, never silently faked.
Nothing is hidden from the power userWhat the editor cannot draw, it shows as it prints and lets you open. Code is one click away, and Split is always available.
Learn by watchingTooltips, the LaTeX path, LaTeX marks and Split make each Word action show its LaTeX, so the user is learning without being taught.
The PDF decidesPage breaks, numbers and the contents come from the last compile, and the app says so. The page view is a faithful sketch, not a second typesetter.

How it fits the code

Keep one model: decorations over the LaTeX

Visual mode today is CodeMirror decorations over the unchanged source (visualModel.ts decides what to draw, visual.ts draws it). Keep that. A separate rich-text model (ProseMirror, a Word-style document tree) would need a LaTeX→tree→LaTeX round trip, and that round trip is exactly what loses a user's writing. Every ribbon button becomes a function in latex.ts that edits the source, like toggleCommand and setHeading do now.

The page is CSS on the editor

Page view is a different style for the same CodeMirror content: no gutter, a white sheet of the paper's width, padding from the margins read out of the preamble (the Document setup code already parses geometry), STIX Two Text. Page gaps are block widgets placed at the source lines where each page starts, which SyncTeX already provides for the jump-to-PDF feature. Re-placing them after each compile is cheap.

The one rule that has to change

Today whatever the cursor touches is shown as source (visualModel.ts, around line 191). A Word user who clicks into a bold word and sees \textbf{ appear will think the document broke. In page view, inline formatting (bold, italic, colour, citations, references) should stay drawn, with the cursor moving through the text as in Word, and source shown only on request: Ctrl+/ on a block, LaTeX marks, or Split. That needs CodeMirror's atomic ranges, so the cursor steps over hidden command text, plus care at the edges (typing at the end of a bold word: inside or outside?). Word's own rule is that typing continues the formatting on the left. Keep today's reveal-on-cursor in Draft view for people who like it.

Split is nearly free

Two EditorViews on one EditorState (CodeMirror syncs them through transactions): one with the visual extensions, one without. Linking the current block is a selection listener on each.

What to measure

Page view redraws under the same budget as today (about 14 ms for 5,000 lines with 50 tables). Every new button gets a unit test that its LaTeX compiles and reads back the same, in the style of the table editor's write-and-read-back check. The keyboard pass covers the ribbon and KeyTips.
